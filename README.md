# 🎓 Repositório de Atividades Acadêmicas

Este repositório foi criado com o objetivo de reunir e organizar todas as atividades, exercícios, projetos e anotações desenvolvidos ao longo do curso de **Engenharia de Software** na **PUC SC**.

## 📚 Conteúdo

O repositório pode conter:

- ✅ Exercícios de lógica de programação
- ✅ Projetos em diferentes linguagens (JavaScript, C, Java, Python, etc.)
- ✅ Trabalhos de disciplinas como Estrutura de Dados, Redes, Engenharia de Requisitos, entre outros
- ✅ Atividades práticas e teóricas
- ✅ Documentações, diagramas e relatórios
- ✅ Anotações de aulas

## 🧠 Finalidade

Este repositório serve como:

- Um **portfólio de aprendizado** ao longo da graduação
- Um **registro pessoal** de desenvolvimento de habilidades técnicas e teóricas
- Uma forma de **compartilhar conhecimento** com colegas e outros estudantes

## 📁 Organização

Os arquivos estão organizados por **disciplinas**, **semestres** ou **temas específicos**, dependendo da atividade.
